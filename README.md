# সাইট সেভ

একটা কাজ: পাবলিক পেজের লিংক দিলে সাধারণ স্ট্যাটিক সাইট জিপ হয়।

আনজিপ করলে এই গঠন পাবেন, আর `index.html` সরাসরি ফোন বা ডেস্কটপ ব্রাউজারে খোলে।

```text
index.html
css/
js/
images/
fonts/
media/
```

লাইভ পেজ: https://omarreact.github.io/web-audit-studio/

## কেন বদলানো হলো

আগের হোমপেজ একসাথে স্ক্যানার, অডিট, Monaco এডিটর, আট রকম ফ্রেমওয়ার্ক এক্সপোর্ট আর AI কনভার্টার ছিল। সেই UI দিয়ে বোঝা যাচ্ছিল না আসল ফল কী। এখন সামনের দরজা শুধু সেভ।

পুরনো টুল সরানো হয়নি। সেটা আছে [`studio.html`](studio.html)-এ। আগের রিডমি আছে [`docs/LEGACY-README.md`](docs/LEGACY-README.md)-এ।

## সীমা

GitHub Pages-এ কোনো প্রক্সি নেই। ব্রাউজার শুধু সেই সাইট আনতে পারে যেটা CORS অনুমতি দেয়। জাভাস্ক্রিপ্ট না চালিয়ে সেভ হয়, তাই অনেক আধুনিক অ্যাপের প্রথম HTML শেলই পাওয়া যায় — পুরো অ্যাপ নয়। সার্ভার কোড, ডাটাবেস বা লগইন-এর পেছনের ফাইল এই টুল দিয়ে আসে না।

নমুনা বাটন নেট ছাড়াই `index.html` + `css/` + `images/` জিপ বানায়, যাতে গঠনটা দেখা যায়।

## চালানো

রুটের `index.html` খুলুন, অথবা:

```bash
python -m http.server 8000
```

Vercel-এ আগের মতো `app.py` দিয়ে পুরনো স্টুডিও ও ক্যাপচার API চালু থাকে। হোমপেজ এখন নতুন সেভ স্ক্রিন।
